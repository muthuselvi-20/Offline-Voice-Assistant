## Install from https://ffmpeg.org/download.html#build-windows
![Download page](<Screenshot 2026-07-05 110510.png>)
- choose Windows builts by BtbN
- choose ffmpeg-master-latest-win64-gpl 
- install 

## In downloads 
- extract the files 
- copy the extracted folder and paste in C:\Program Files\ffmpeg-master-latest-win64-gpl-shared
- open bin in that folder
- copy the path 

## In search 
- type env
- click environment variable 
- in system variable choose path -> edit -> new -> add the copied path -> ok for all

## In command prompt 
- cd paste path copied 
- directory change
- type ffmpeg
